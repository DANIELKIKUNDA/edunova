# ADR-021 — Assessment & Exam Simulation
Décision: bounded context `assessment` séparé de Learning Experience. Les questions portent une provenance; le blueprint définit l'intention d'évaluation; la tentative fige les question_ids; le résultat est dérivé et explicable. La maîtrise reste calculée par les moteurs pédagogiques et n'est pas décrétée par un score isolé.
