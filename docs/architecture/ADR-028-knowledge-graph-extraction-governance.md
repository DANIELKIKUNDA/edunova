# ADR-028 — Knowledge Graph extraction, governance and orchestration

Status: Accepted — EduNova 0.21.1.

Course-derived graph facts enter as candidates with an immutable source revision, SHA-256, source locator, confidence and fingerprint. Extraction is assistance, not publication. Review is explicit and high-stakes acceptance rejects low-confidence candidates; published graph relations continue to require the LOT20 governance workflow. Duplicate candidates are fingerprinted. Dependency cycles remain forbidden. Learning sequencing consumes published dependency edges only. Graph health exposes orphan concepts and review backlog. The graph selects pedagogical structure but never acts as an unsourced scientific answer key.
