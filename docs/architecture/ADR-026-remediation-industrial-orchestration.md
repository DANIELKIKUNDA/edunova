# ADR-026 — Remediation industrial orchestration

Status: Accepted — EduNova v0.20.2.

LOT 19 closes with an append-only learning-event trail for diagnosis, path creation, practice, verification, retention and relapse. Offline practice mutations carry a client mutation id and are idempotent. A remediation path keeps longitudinal counters and cumulative measured gain. Tutor strategy may use a learner's own prior intervention outcomes only after a minimum evidence threshold; otherwise the deterministic root-cause policy remains authoritative.

The event stream is an integration seam for LOT 16 adaptive intelligence, LOT 17 planning, LOT 18 assessment/Error Bank and future analytics. It does not grant an LLM authority to declare mastery. Resolution still requires independent verification and transfer; retention remains a later check.
