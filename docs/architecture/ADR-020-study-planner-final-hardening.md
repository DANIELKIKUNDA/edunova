# ADR-020 — LOT 17 final hardening

Le plan d'étude est une projection révisable, jamais une vérité académique. Les items `done` sont historiques et ne sont pas écrasés par une régénération; seuls les items encore `planned` sont superseded. `row_version` est le jeton de concurrence pour les transitions multi-device. Les index partiels 0019 optimisent l'exécution et la replanification sans modifier les données historiques.
