# ADR-030 — EduNova Tutor 2.0

Tutor 2.0 extends the existing grounded assistant instead of replacing it. A deterministic pedagogical policy selects a move (Socratic question, progressive hint, explanation, prerequisite repair, remediation, practice or abstention) from evidence produced by LOT16–20. LLM providers may realize wording but do not decide mastery. High-stakes tutoring requires validated source evidence. Offline mutations are idempotent and sessions use optimistic versions.
