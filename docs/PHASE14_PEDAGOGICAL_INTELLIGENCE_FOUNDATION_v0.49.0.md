# EduNova v0.49.0 — Phase 14 Pedagogical Intelligence Foundation

Introduces an explainable, deterministic teacher-support engine over aggregated learning-objective evidence. It deliberately does not automate grades, diagnose learners, or claim predictive AI. Low evidence yields a collect-more-evidence recommendation rather than a mastery conclusion. Existing pedagogy/adaptive-learning engines remain canonical; this module adds teacher-facing aggregate interpretation instead of duplicating student adaptation.
