# EduNova v0.49.4 — Phase 14 Teacher Dashboard

This checkpoint deepens Phase 14 with an explainable teacher dashboard built on canonical objective evidence.

## Added
- deterministic objective prioritization (high/watch/normal/unassessed)
- coverage exposed per learning objective
- dashboard summary counts
- prioritized teacher actions carrying action, reason, and confidence
- recurrent-error count and existing descriptive assessment timeline
- explicit guardrail that prioritization is decision support and the teacher remains final decision-maker

No predictive learner model, diagnosis, automatic grade change, jury action, or Student Success mutation is introduced.
