# EduNova v0.49.3 — Phase 14 Trends & Recurrent Errors

Adds teacher-facing descriptive assessment timelines and group-level recurrent incorrect-response signals over canonical objective/question evidence.

Guardrails: no learner diagnosis, no predictive model, no automated grading/jury action, and no claim that different assessments are psychometrically equivalent. A recurrent incorrect response is a pedagogical signal, not proof of a causal misconception.
