# LOT 20 — Knowledge Graph & Academic Knowledge Intelligence — v0.21.0

This lot introduces the governed academic graph: typed/versioned nodes and relations, provenance, candidate→validated→published workflow, high-stakes gates, cycle prevention, bounded prerequisite/dependent traversal, root-cause candidate ranking, and assessment context projection.

The graph does not replace source-grounded content. It answers *which concepts are connected and in what pedagogical order*; validated editorial sources remain authoritative for *what is scientifically true*.

Integrations: LOT16 can consume prerequisite evidence; LOT17 can order prerequisite-first work; LOT18 receives prerequisite/transfer concept context; LOT19 can distinguish symptom concept from weaker upstream prerequisites.

OPEN-machine: PostgreSQL migration/concurrency/load, large graph traversal benchmarks, Flutter analyze/test/build, device accessibility, real curriculum validation, medical expert review.
