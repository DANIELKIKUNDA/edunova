# LOT 19 FINAL — Remediation Intelligence & Tutor Engine — v0.20.1

This hardening turns remediation-v1 into an explainable tutor loop: evidence sufficiency, root-cause hypothesis, intervention selection, progressive hints, adaptive difficulty 1–5, mandatory transfer, independent verification, spaced retention and relapse reopening.

## Cognitive safeguards
- A single error is insufficient for a confident misconception claim.
- Reading an explanation is not mastery evidence.
- Heavy hint use does not count as independent success.
- Transfer must succeed before resolution.
- Retention failure reopens the gap.
- Medical/high-stakes explanations require validated source content.
