# EduNova v0.49.5 — Phase 14 adversarial audit

This checkpoint hardens teacher-facing pedagogical intelligence before Phase 15.

- Canonical objective/trend evidence is restricted to active learners enrolled in the offering cohort.
- Question→objective mappings and blueprint→offering bindings are conflict-safe and cannot be silently hijacked by another institution/offering.
- Teacher-facing evidence no longer exposes per-attempt identifiers; aggregate evidence hashes preserve provenance without turning the dashboard into learner profiling.
- Tenant/offering access remains checked before analysis.
- Rules remain deterministic and non-predictive; no automatic grading, jury, diagnosis, or Student Success action is performed.

External/device/Flutter/provider certification is out of scope for this backend checkpoint.
