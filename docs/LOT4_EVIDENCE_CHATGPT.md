# LOT 4 — Preuves environnement ChatGPT

Le SDK Flutter n’est pas installé dans cet environnement ; aucune certification Flutter n’est revendiquée.

Le backend Python et les règles de domaine sont exécutés réellement. La preuve brute du dernier `pytest -q` est enregistrée sous `docs/evidence/lot4/backend_test_run.txt`.

Points particulièrement testés :
- disponibilité/occupations ;
- énergie/cognition ;
- pauses ;
- capacité ;
- prérequis ;
- reports ;
- horizon ;
- surcharge ;
- stabilité ;
- notifications ;
- périmètres d’évaluation ;
- adhérence réelle.
