# EduNova Studio — Workflow LOT 11

1. **Ingestion** : PDF/photo/OCR/questionnaire entre dans la file de travail.
2. **Édition** : nettoyage, structure, métadonnées, provenance, droits et classification de risque.
3. **Révision** : snapshot immuable du contenu ; origine IA et version du prompt conservées.
4. **Relecture** : acceptation ou corrections demandées, commentaire obligatoire recommandé.
5. **Approbation** : le contenu est prêt mais pas encore public.
6. **Publication** : projection vers la Bibliothèque EduNova, changelog et version académique.
7. **Nouvelle version** : ancienne version reste servie tant que la nouvelle n'est pas approuvée.
8. **Archivage** : conservation de l'historique et retrait contrôlé du cycle actif.

## Documents/photos d'anciennes interrogations
Une photo OCRisée reste une **source**, pas une vérité. Les questions extraites doivent être vérifiées avant publication. Les sujets d'origine doivent conserver source, année, type (interrogation/examen), statut de droits et niveau de confiance OCR.
