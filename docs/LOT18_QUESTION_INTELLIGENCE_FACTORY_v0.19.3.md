# LOT 18.3 — Question Intelligence Factory / Past Papers Intelligence

Pipeline: historical paper → parser → immutable original → SHA-256/fingerprint → duplicate gate → Bloom inference + confidence → draft question → quality gate → human review → approved bank → exam blueprint.

Supported interchange: GIFT and Moodle XML. Imported questions are never approved automatically. Bloom inference is advisory. Variant specifications preserve the learning objective and source grounding while explicitly forbidding verbatim copying and answer leakage.
